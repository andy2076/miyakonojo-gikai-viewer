# 本番反映手順（令和8年第2〜4回定例会の追加）

VPS（ConoHa / `160.251.179.150`）上で実行する。
アプリは `/root/miyakonojo-gikai-viewer`、DBはDockerコンテナ `my-db` の PostgreSQL（DB名 `gikai`）。

> データを書き換える手順が3つ（議員名の空白除去 / 成合の統合 / カード投入）ある。
> **いずれも先に確認実行（`--apply` なし）を挟むこと。**

## 0. バックアップを取る

**必ず最初に実行する。** 何かあればここに戻す。

```bash
cd /root/miyakonojo-gikai-viewer
mkdir -p backups

STAMP=$(date +%Y%m%d-%H%M%S)
docker exec my-db pg_dump -U postgres -d gikai -Fc > backups/gikai-${STAMP}.dump

# 取れたことを確認（0バイトでないこと）
ls -lh backups/gikai-${STAMP}.dump
echo "BACKUP=backups/gikai-${STAMP}.dump"
```

念のため、書き換え対象テーブルの件数も控えておく。

```bash
docker exec my-db psql -U postgres -d gikai -c "
SELECT 'question_cards' AS t, count(*) FROM question_cards
UNION ALL SELECT 'meetings', count(*) FROM meetings
UNION ALL SELECT 'meeting_topics', count(*) FROM meeting_topics;"
```

### 戻すとき

```bash
docker exec -i my-db pg_restore -U postgres -d gikai --clean --if-exists < backups/gikai-<STAMP>.dump
```

## 2. 議員名の空白を除去する（確認 → 実行）

令和7年第4回のインポート時に「川内 賢幸」のような空白入りの表記が18件入っており、
同一人物が別集計になっている。空白なしの表記に統一する。

```bash
# ① 確認だけ（18件が表示されるはず）
npx tsx scripts/normalize-member-names.ts
```

出力を目視して、統合先がすべて既存の表記であることを確認してから実行する。

```bash
# ② 実行
npx tsx scripts/normalize-member-names.ts --apply
```

## 3. 成合円美佳 → 成合まるみか を統合する（確認 → 実行）

令和8年1月の改選以降、概要書・会議録とも「成合 まるみか」表記になっている。
読みが一致し、会議録の出席議員名簿にも「成合 まるみか」しか無いため同一人物として統合する。

```bash
# ① 確認だけ（15件・対象の会期一覧が表示される）
npx tsx scripts/merge-member-aliases.ts
```

対象が「成合円美佳 15件 → 成合まるみか」であることを確認してから実行する。

```bash
# ② 実行
npx tsx scripts/merge-member-aliases.ts --apply
```

確認:

```bash
docker exec my-db psql -U postgres -d gikai -c "
SELECT member_name, count(*) FROM question_cards WHERE member_name LIKE '成合%' GROUP BY 1;"
# -> 成合まるみか | 18   （成合円美佳 が残っていないこと）
```

## 5. 件数を検証する

期待値: 3月 = 16名 / 43大項目 / 125小項目、6月 = 19 / 48 / 166、9月 = 21 / 54 / 195。

```bash
docker exec my-db psql -U postgres -d gikai -c "
SELECT
  c.meeting_title,
  count(*)                                       AS 議員数,
  sum(jsonb_array_length(c.themes))              AS 大項目,
  sum((SELECT count(*)
         FROM jsonb_array_elements(c.themes) t,
              jsonb_array_elements_text(t->'subtopics'))) AS 小項目
FROM question_cards c
WHERE c.meeting_title LIKE '令和８年%'
GROUP BY c.meeting_title
ORDER BY c.meeting_title;"
```

期待される出力:

```
      meeting_title      | 議員数 | 大項目 | 小項目
-------------------------+--------+--------+--------
 令和８年第２回定例会    |     16 |     43 |    125
 令和８年第３回定例会    |     19 |     48 |    166
 令和８年第４回定例会    |     21 |     54 |    195
```

期待値と一致することを1行の判定で確認する（`OK` が3行出れば正常）。

```bash
docker exec my-db psql -U postgres -d gikai -c "
WITH actual AS (
  SELECT c.meeting_title AS t,
         count(*)::int AS m,
         sum(jsonb_array_length(c.themes))::int AS b,
         sum((SELECT count(*)
                FROM jsonb_array_elements(c.themes) th,
                     jsonb_array_elements_text(th->'subtopics')))::int AS s
    FROM question_cards c
   WHERE c.meeting_title LIKE '令和８年%'
   GROUP BY c.meeting_title
), expected(t, m, b, s) AS (
  VALUES ('令和８年第２回定例会', 16, 43, 125),
         ('令和８年第３回定例会', 19, 48, 166),
         ('令和８年第４回定例会', 21, 54, 195)
)
SELECT e.t,
       CASE WHEN a.m = e.m AND a.b = e.b AND a.s = e.s
            THEN 'OK'
            ELSE format('NG 実績=%s/%s/%s 期待=%s/%s/%s',
                        a.m, a.b, a.s, e.m, e.b, e.s)
       END AS result
  FROM expected e LEFT JOIN actual a ON a.t = e.t
 ORDER BY e.t;"
```

あわせて、答弁の収録状況（3月のみ答弁あり）も確認する。

```bash
docker exec my-db psql -U postgres -d gikai -c "
SELECT c.meeting_title,
       count(*) FILTER (WHERE t->>'answer_point' <> '') AS 答弁あり,
       count(*) FILTER (WHERE t->>'answer_point' = '')  AS 答弁なし
  FROM question_cards c, jsonb_array_elements(c.themes) t
 WHERE c.meeting_title LIKE '令和８年%'
 GROUP BY c.meeting_title ORDER BY 1;"
# -> 第２回: 43/0、第３回: 0/48、第４回: 0/54
```

議員名の重複が残っていないことも見ておく。

```bash
docker exec my-db psql -U postgres -d gikai -c "
SELECT member_name FROM question_cards
 WHERE member_name <> replace(replace(member_name,' ',''),'　','')
 GROUP BY 1;"
# -> 0行
```
